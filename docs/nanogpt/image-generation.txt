#### Authorizations

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#authorization-authorization)

Authorization

string

header

required

Bearer authentication header of the form `Bearer <token>`, where `<token>` is your auth token.

#### Body

application/json

Parameters for image generation

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-prompt)

prompt

string

required

The text prompt to generate an image from

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-model)

model

string

default:hidream

The model to use for generation

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-n)

n

integer

default:1

Number of images to generate

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-size)

size

enum<string>

The size of the generated images

Available options:

`256x256`,

`512x512`,

`1024x1024`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-response-format)

response\_format

enum<string>

The format in which the generated images are returned

Available options:

`url`,

`b64_json`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-user)

user

string

A unique identifier representing your end-user

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-image-data-url)

imageDataUrl

string

Base64-encoded image data URL for img2img generation. Single image input for models that support image-to-image transformation. Format: data:image/\[type\];base64,\[data\]. Note: Direct URL input is not supported - images must be converted to base64 data URLs before submission.

Example:

`"data:image/jpeg;base64,/9j/4AAQ..."`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-image-data-urls)

imageDataUrls

string<data-url>\[\]

Array of base64-encoded image data URLs for models supporting multiple image inputs (e.g., flux-kontext, gpt-4o-image, gpt-image-1). Each URL must follow the format: data:image/\[type\];base64,\[data\]

Example:

```
[\
  "data:image/jpeg;base64,/9j/4AAQ...",\
  "data:image/png;base64,iVBORw0KGgo..."\
]
```

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-mask-data-url)

maskDataUrl

string

Base64-encoded mask image data URL for inpainting models (e.g., flux-lora/inpainting). White areas indicate regions to edit. Format: data:image/\[type\];base64,\[data\]

Example:

`"data:image/png;base64,iVBORw0KGgo..."`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-strength)

strength

number

default:0.8

Controls how much the output differs from the input image in img2img mode. Lower values produce outputs closer to the input.

Required range: `0 <= x <= 1`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-guidance-scale)

guidance\_scale

number

default:7.5

How closely the model follows the text prompt. Higher values result in images more closely aligned with the prompt.

Required range: `0 <= x <= 20`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-num-inference-steps)

num\_inference\_steps

integer

default:30

Number of denoising steps. More steps generally produce higher quality but take longer.

Required range: `1 <= x <= 100`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-seed)

seed

integer

Random seed for reproducible generation. Use the same seed with the same parameters to get identical results.

Example:

`42`

[​](https://docs.nano-gpt.com/api-reference/endpoint/image-generation-openai#body-kontext-max-mode)

kontext\_max\_mode

boolean

default:false

Enable enhanced context mode for flux-kontext model. Provides better understanding of input images.
